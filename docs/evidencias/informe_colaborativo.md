## 4. Flujo de trabajo aplicado

1. Clonado del repositorio.
2. Creación de ramas individuales.
3. Desarrollo de estructura por responsabilidad.
4. Commit individual.
5. Push hacia GitHub.
6. Creación de Pull Request.
7. Revisión y merge hacia main.
8. Actualización local con git pull.

## 5. Conclusión

El equipo implementó un flujo colaborativo basado en Git, GitHub, ramas, commits, pull requests e integración continua. Esta trazabilidad permite demostrar la participación individual de cada integrante y la evolución técnica del proyecto ArepIA.
